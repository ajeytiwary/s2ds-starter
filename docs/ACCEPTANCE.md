# Handover acceptance

- [ ] New student runs the demo from a clean environment.
- [ ] Tests pass, and report links/CSV output agree with metrics.
- [ ] Synthetic versus real inputs are explicitly identified.
- [ ] Every real AOI, scene, field record and intervention date has provenance and a license decision.
- [ ] QC exclusions and missing-data coverage are reported.
- [ ] Site/geographic split and independent labels are frozen before model selection.
- [ ] Test data is used once for final evaluation; uncertainty and sample counts accompany scores.
- [ ] Seasonal/weather confounding, missing field records and selection bias are assessed.
- [ ] Reproduction instructions, experiment ledger and a limitation statement are included.
- [ ] Manager report makes supported claims; no biodiversity/carbon/causal inference from NDVI alone.
