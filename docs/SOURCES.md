# Sources to investigate

These are discovery starting points, not prevalidated datasets or completed integrations. Confirm access, licensing, site IDs and temporal overlap before selecting an AOI.

| Source | Purpose | Starting URL |
|---|---|---|
| Copernicus Data Space | Sentinel-1/2 scene discovery and products | https://dataspace.copernicus.eu/ |
| ECMWF Climate Data Store | ERA5 covariates | https://cds.climate.copernicus.eu/ |
| NatureScot | Peatland ACTION project and monitoring resources | https://www.nature.scot/ |
| Finnish Environment Institute | Environmental and peatland data discovery | https://www.syke.fi/en |
| Zenodo | Published EO datasets and scientific reference records | https://zenodo.org/ |
| European Environment Agency | Natura 2000 context; not intervention ground truth | https://www.eea.europa.eu/ |

Never interpret site boundaries as proof of restoration success. Prefer a small verified AOI with usable dated field labels over a large unlabelled catalogue. Do not scrape or redistribute restricted records.
